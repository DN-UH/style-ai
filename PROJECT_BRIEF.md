# Style Ai Project Brief

## Vision

Style Ai is a global luxury AI fashion assistant that helps clients discover, refine, and act on a personal style direction. The MVP presents a premium mobile-first experience with mock AI outputs, upload and questionnaire placeholders, pricing, account surfaces, and affiliate-oriented commerce readiness.

## Audience

- Luxury shoppers who want curated wardrobe, occasion, and travel styling guidance.
- Personal stylists and concierge teams validating an AI-assisted styling workflow.
- Affiliate and brand partners who need transparent performance surfaces.

## MVP Goal

Ship a production-oriented Next.js foundation that demonstrates the core journey without paid API integrations:

1. Visitor understands the product promise.
2. Visitor reviews pricing.
3. User starts onboarding.
4. User sees a photo upload placeholder.
5. User answers a style questionnaire placeholder.
6. User lands on a mock AI result dashboard.
7. Affiliate partner can view a mock affiliate dashboard.
8. User can access account and theme settings.

## Brand Direction

Default visual theme is black and gold luxury: editorial, calm, precise, and premium. The design system must support selectable visual themes so the brand can later expand into other seasonal, regional, or partner-led styles without rewriting UI components.

## Constraints

- Use Next.js App Router, TypeScript, and Tailwind CSS.
- Launch first as a mobile-friendly PWA/web app to avoid App Store and Play Store commissions.
- Keep architecture Supabase-ready, Paddle-ready, and PayHere-aware, but do not connect live paid services yet.
- Use mock data for all AI, commerce, account, and affiliate surfaces.
- Prioritize mobile-first PWA behavior.
- Keep code clean, typed, and easy to extend.
