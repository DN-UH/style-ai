# Style Ai

Style Ai is a global luxury AI fashion assistant MVP. This repository is intentionally built with mock data first, with clean boundaries for later Supabase, Paddle, PayHere, affiliate, and AI integrations.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Mobile-first PWA shell
- User-selectable visual themes
- Supabase-ready placeholders
- Paddle-ready subscription placeholders
- PayHere backup payment placeholders
- Day-one affiliate/referral strategy

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## MVP Routes

- `/`
- `/pricing`
- `/onboarding`
- `/onboarding/photo-upload`
- `/onboarding/questionnaire`
- `/dashboard`
- `/affiliate`
- `/account`

## Integration Policy

The MVP does not call paid APIs. AI, Supabase, Paddle, PayHere, affiliate, and account data are mocked until their implementation tasks are approved.
